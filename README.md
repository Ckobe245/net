# 小c 个人网站 — 第一阶段（纯静态欢迎页）

根据《个人网站-第一阶段方案.md》规划搭建的纯静态欢迎页工程。

## 技术栈

- **框架**: Next.js 15 (App Router, `output: 'export'`)
- **语言**: TypeScript 5
- **样式**: Tailwind CSS 4 (暗黑主题)
- **动画**: Framer Motion 12
- **包管理**: pnpm Workspace

## 视觉与交互特性

- **流动光晕背景（Canvas）**: 暖金（`#d4a574`，代表生活日常）与冷绿/冷青（`#5eead4`，代表科技AI）双色流体缓慢流动，具备鼠标位移跟随与微弱聚光交互。
- **首屏标题渐入**: 优雅的圆环头像徽章，带流光边框、渐入与副标题联动。
- **打字机自我介绍**: 进入视口（IntersectionObserver）触发逐字呈现与光标闪动。
- **多平台矩阵引流**: 涵盖抖音、B站、小红书、微信视频号、微信公众号。
- **公众号二维码弹窗**: 支持点击展开模态框、ESC键或点击遮罩关闭。
- **多端响应式**: 针对桌面端、平板端、手机端做了栅格与布局适配。

## 本地启动

```bash
# 1. 安装依赖
pnpm install

# 2. 启动开发服务器
pnpm dev
# 或直接进入前端目录：
cd apps/web && pnpm dev
```

本地访问：`http://localhost:3000`

## 构建导出（静态产物）

```bash
pnpm build
```

构建生成的纯静态文件保存在 `apps/web/out/` 目录中。

## 部署（Nginx 静态托管）

直接将 `apps/web/out/` 目录下的所有文件上传至服务器对应的 web 静态根目录（如 `/opt/site`）即可。
